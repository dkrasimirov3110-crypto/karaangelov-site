# Built to connect

Личният сайт на Дамян Караангелов: 3D град от блокчета, в който всяка сграда е проект.

Статичен сайт (HTML + three.js), без build стъпка. Съдържанието е в `data.js`, градът е в `app.js`.

## Текстови версии
След промяна в `data.js` пуснете `node scripts/build-text.mjs`. Скриптът обновява `ai.md` (изгледа „AI“) и скрития текст за търсачки в `index.html`.
Правилата за писане са в `WRITING.md`.
